# Mamou Asman Resume Site

Static English resume website prepared for GitHub Pages.

## Files

- `index.html` - the complete resume page with embedded CSS and print styles.
- `assets/backend-systems-hero.png` - local visual asset used by the hero section.

## GitHub Pages

1. Create a public repository, for example `resume`.
2. Put `index.html` and the `assets` folder in the repository root.
3. In GitHub, open `Settings -> Pages`.
4. Select `Deploy from a branch`, choose `main` and `/root`.
5. Open the generated Pages URL after deployment.

## PDF

Open `index.html` in a browser and use the `Print / Save PDF` button.
